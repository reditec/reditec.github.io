A free open source file explorer
for Red Dead Redemption

What is it?

RDRExplorer is an open source Red Dead Redemption file explorer that is very easy to use.
With it you can see and extract all game files of Red Dead Redemption's RPF archives.

The difference from other RPF explorers is that it has the biggest list of file names currently known.
