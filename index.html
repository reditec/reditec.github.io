For offline modding only, with your own copy of the game. SparkIV contains no game data and no keys: it reads them from the game files on your PC. We expressly distance ourselves from any use of SparkIV for online modding or cheating.

Supported games

GTA IV is supported fully, including editing. Red Dead Redemption 2 and GTA VI are new and experimental: their files can be browsed and many of them viewed, but not changed yet.

Grand Theft Auto IV
and Episodes from Liberty City

PCFull support
  • IMG and RPF archives of GTA IV, The Lost and Damned and The Ballad of Gay Tony, with file names
  • Cutscenes that render like the game: cast, camera, lights, sound, subtitles
  • Models, textures, animations, audio, scripts, collision, web pages
  • Edit mode: replace and import files, with backups

The archives' key is read from your game's executable.

Red Dead Redemption 2

PCExperimental · read-only
  • RPF8 archives, with the file names of the RAGE-StringsDatabase
  • Metadata as XML, every file in the hex view, export of any file
  • Textures, models and audio: not yet
  • Editing: not yet

A one-time setup assistant reads the archives' keys from the running game.

Grand Theft Auto VI

Xbox SeriesExperimental · read-only
  • RPF9 archives, also archives inside archives; encrypted and compressed files open as their real content
  • File names recovered from the game's own strings (most files)
  • Textures (.ztd), texture pools (.ttpf) and audio (.awc, also the radio stations)
  • Models: not yet
  • Editing: not yet

The archives' cipher is read from the game's own executable.

Get started

You need a legally owned copy of at least one of the supported games.

Download

Get reditec.SparkIV-win-Setup.exe from the releases.

Install

Run it. As the app isn't signed yet, Windows may warn you: choose "More info", then "Run anyway".

Choose your game

Pick the game and show SparkIV its folder once. New versions install with one click and show what's new.

What's new in 0.9.0 Alpha 7

Released on November 25, 2026. SparkIV opens Red Dead Redemption 2 and Grand Theft Auto VI, and the cutscenes come closer to the game.

  • Red Dead Redemption 2 (PC), experimental and read-only: the RPF8 archives with their file names; a one-time assistant reads the keys from the running game.
  • Grand Theft Auto VI (Xbox Series), experimental and read-only: the RPF9 archives, also archives inside archives; encrypted and compressed files open as their real content.
  • GTA VI's textures, texture pools and audio open in the same viewers as GTA IV's.
  • One "Choose Game" button opens the game selector.
  • Cutscenes: street lamps and traffic lights glow, the map's smoke and steam show; headlamps, lamp shadows, characters, sky, water and fog are closer to the game.
  • New settings "Texture filtering" and "Smooth edges" for the 3D views.

All versions: changelog · release on GitHub

Where it's heading

Version 1.0 will be the first that fully supports GTA IV on PC:

  • every file of the game opens;
  • all cutscenes look as they do in the game;
  • export, edit and import, compatible with OpenIV's openFormats.

Red Dead Redemption 2 and GTA VI will get more viewers step by step. Known differences from the game are tracked in the issues.

Open source

SparkIV is free software under the GNU General Public License v3.

It was started by aru in 2008 and carried on by Ahmed Walid and Silent Spud. reditec has rebuilt it as a WinUI app since 2026 and added Red Dead Redemption 2 and GTA VI, with help from PB07 on GTA VI's file names and decryption. Contributions and bug reports are welcome on GitHub.
