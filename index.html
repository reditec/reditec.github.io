SparkIV

A free file browser, viewer and editor for Grand Theft Auto IV and Episodes from Liberty City on PC, with a cutscene viewer that renders like the game.

Download Source on GitHub
Windows 10 or later, x64 · updates itself after installing

What it does

Open the game's archives, look inside every file and change them safely. SparkIV reads the files of your own copy of the game; it contains no game data.

Archives

Browse the IMG and RPF archives of GTA IV, The Lost and Damned and The Ballad of Gay Tony.

Cutscenes .cut

Plays the cutscenes with cast, camera, lights, sound and location, lit and shaded the way the game does it.

Models .wdr .wdd .wft

Models in 3D, with their textures and shaders.

Textures .wtd

View and export the textures of a dictionary.

Animations .wad

Play the animations of a dictionary.

Audio .ivaud

Listen to sound banks, including multichannel tracks, and export them.

Scripts .sco

Decompiled or disassembled mission scripts.

Collision .wbn .wbd

See the collision of the map.

Editing

Replace and import files in an edit mode. The original of every file is backed up before SparkIV first writes to it.

Get started

A legally owned copy of GTA IV or Episodes from Liberty City for PC is required.

Download

Get reditec.SparkIV-win-Setup.exe from the releases.

Install

Run it. As the app isn't signed yet, Windows may warn you: choose "More info", then "Run anyway".

Open your game

SparkIV finds the game folder or asks for it. New versions install with one click; the channel is set in Settings → Updates.

Where it's heading

Version 1.0 will be the first that fully supports GTA IV on PC:

  • every file of the game opens;
  • all cutscenes look as they do in the game;
  • export, edit and import, compatible with OpenIV's openFormats.

Known differences from the game are tracked in the issues.
